# Arsitektur

Alternatif yang dipilih: Node 22 + Express + React/Vite + MySQL 8 (`mysql2`). React/Vite menangani UI dan bundling; Express menyediakan API kecil untuk antrean dan media, sementara worker Node terpisah memproses pekerjaan persisten tanpa terikat siklus request. Pemisahan ini menjaga aplikasi lokal sederhana dan worker dapat dijalankan/restart secara mandiri. Backend tetap server-side, satu origin 127.0.0.1:8072, sesi HttpOnly, API/assets terlindungi, worker persisten proses terpisah. Tidak ada dependency Hermes. Vite hanya bundler frontend; produksi Express melayani dist setelah autentikasi. Worker tidak diimpor/dijalankan dari HTTP bootstrap.

MySQL InnoDB dengan transaksi + `SELECT … FOR UPDATE` untuk klaim job; satu job aktif per bab/jenis dijaga kolom `active_key` unik. Stok gambar adalah kolam bersama (`assets`), bab mengikat gambar lewat `chapter_stock`. Konten, status domain dan job dipisahkan. File hasil hanya di output. Sumber queue/skill/template dibaca saja. Preview mempunyai manifest `template-only`, tidak dianggap produksi final. Save artikel membatalkan job aktif dan menghapus pointer preview/audio/visual sehingga worker lama tidak bisa menandai versi baru selesai.

Kontrak NC-WA lokal yang diperiksa: `nc-wa-official/src/components/instagram/domain/integration-openapi.ts` baris 212–243 dan `official-posts.ts`: POST /posts mewajibkan imageUrl, createOfficialPost memanggil Meta dengan image_url. Tidak ada kontrak Reels terbukti. Adapter hanya GET akun/status, semua POST publishing ditolak sebelum network. Karena submission belum diimplementasikan, tidak dibuat requestId palsu/claim published.

Codex runner: argv shell:false, EOF stdin, cwd per job, env allowlist tanpa key aplikasi/API; ignore config/rules, ephemeral, read-only. Ini bukan isolasi OS yang mencegah seluruh pembacaan filesystem: artikel runner menonaktifkan shell/tools melalui konfigurasi dan preflight, tetap jangan memberi teks rahasia ke prompt. Exposure publik memerlukan audit isolasi tambahan bila CLI tools diaktifkan. Login resmi melalui terminal, bukan browser.
